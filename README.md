# 🎌 Python Anime Matcher

A beginner-friendly Python script that recommends anime from **Crunchyroll** based on your current mood and preferences. Perfect for learning Python while exploring your favorite anime!

## ✨ Features

- 🎬 **50+ Popular Anime** curated from Crunchyroll
- 😄 **6 Mood Categories**: Happy, Sad, Excited, Relaxed, Thoughtful, and Romantic
- 📊 **Real Anime Data**: Episode counts and ratings included
- 🎯 **Interactive Menu**: User-friendly CLI interface
- 💻 **Beginner-Friendly Code**: Well-commented and easy to understand
- 🔧 **Easily Customizable**: Add your own anime to the database!

## 📋 Requirements

- Python 3.6 or higher
- No external dependencies required! (Uses only built-in Python modules)
